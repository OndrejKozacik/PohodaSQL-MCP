# PohodaSQL-MCP
Samostatný MCP server (Node, stdio) pro psaní a ověřování **T-SQL nad databází účetního programu POHODA** (Stormware). Dává AI asistentovi v Claude Desktop, Claude Code nebo Codexu doménová pravidla, schéma databáze, nápovědu programu, kontrolu skriptu proti schématu a volitelně read-only spuštění dotazu.
